# Windpower-Prediction-by-using-AI-tools
Code implementations for wind power prediction using AI tools, including SARIMAX, TCN, and a hybrid SARIMAX+TCN+Random Forest pipeline.


This repository contains code for forecasting wind power output using statistical and machine learning models. Accurate prediction of wind power is essential for grid stability, market operations, and renewable energy integration.

The repository includes three implementations:

  SARIMAX Model – Captures linear temporal dependencies and seasonality.

  Temporal Convolutional Network (TCN) – Models complex non-linear patterns in the data.

  Hybrid SARIMAX + TCN + Random Forest – Combines linear and non-linear modeling with ensemble learning to achieve        improved accuracy.



Development of a user interface (UI) for real-time prediction and visualization. (Future Work)
